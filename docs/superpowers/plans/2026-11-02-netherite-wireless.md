# 下界合金无线终端与无限管理器实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan inline, followed by one fresh-context whole-change review.

**Goal:** 无频率、跨维度、无限距离地批量激活已登记的无线红石终端，包括未加载区块中的终端。

**Architecture:** 主世界 SavedData 保存终端身份、放置者 UUID/名称、维度、坐标、名字、公开状态及激活期限。终端方块与手持管理器共用分页菜单；服务端过滤可见列表、校验操作权限。NeoForge TicketController 为目标申请独立的完整 ticking 票据，服务器 tick 负责信号归零与票据释放。

**Tech Stack:** Minecraft 1.21.1, NeoForge 21.1.219, Create 6.0.10-280, Java 21。

**Spec:** 本计划的以下约束为本次完整规格，由用户请求、信号持续时间答复及项目 AGENTS.md 确定。

## 约束与决定

- 用户选择：输出强度 15、持续 20 tick；区块加载持续 300 tick，重复发送刷新两项期限。
- 名称显示为“放置玩家名的终端名”；UUID 决定所有权，同名终端仍有独立身份。
- 默认私有，仅所有者和其他玩家公开的终端可见、可激活。只有所有者可以改名和公开。
- 管理器为手持工具，支持跨页多选、当前页全选、清空及批量发送。打开列表不加载目标区块。
- 拆除注销；重新放置产生新身份。保存和重启保留登记，旧票据在启动时清理，只恢复未过期的本功能租期。
- 防火、防爆；没有思索时使用 Create 原生 Shift 概要。版本更新为 0.3.1。
- 不使用 RTX 5060、不启动图形客户端；优先使用无图形回归和独立 GameTest 服务端核对关键行为。
- 贴图交给用户指定的既有贴图对话，本对话只接入资源。

## 风险与对应验证

- 伪造客户端请求访问私有终端：服务端逐项检查，测试非所有者不可见、不可编辑、不可激活。
- 未加载/跨维度目标：全局登记查询不取 chunk；真实服务器检查目标加载、输出及延时释放。
- 重复激活、同一 chunk 多个终端：独立 UUID 票据与期限，测试续期和单个到期不影响另一个。
- 重启及信号过期：期限用主世界游戏时间保存，测试序列化与边界；启动回调清理旧票据。
- 移除、替换与失效记录：操作前校验实际 BE 的身份，测试注销与不同 UUID 不误激活。
